## 1. 项目是什么

纯前端简历编辑器：所见即所得编辑、主题切换、分页、自定义 CSS、JSON 导入导出、浏览器打印导出 PDF。

**刻意不做的事：**

- 无登录 / 注册
- 无后端 / 无数据库
- 无收费 / 无广告
- 简历数据只存在用户浏览器 `localStorage`

设计取舍的核心是：**自由度优先**（模块可增删、字段可不填、排版可控），而不是做成招聘站那种强约束表单。

## 2. 技术栈一览

## 3. 5 分钟跑起来

### 环境

- Node.js >= 18
- pnpm（推荐直接 `corepack enable`）

### 命令

```bash
pnpm install
pnpm dev          # http://127.0.0.1:5173/resume/
pnpm build        # tsc + vite build
pnpm preview      # 预览构建产物
pnpm lint         # biome lint
pnpm type-check   # tsc --noEmit
pnpm check        # biome check
```

注意：开发地址必须带 `/resume/`，因为 Vite `base` 和 Router `basename` 都是 `/resume`。

### Docker 本地验证（可选）

```bash
docker build -t resumaker .
docker run --rm -p 8080:80 resumaker
# 访问 http://localhost:8080/resume/
```

## 5. 核心数据模型

定义在 `src/types/resume.ts`。整份简历就是一个 `Resume`：

```ts
Resume
├── sections: ResumeSection[]     // 模块列表
│   ├── type: 'basic' | 'timeline'
│   ├── visible / order / pageNumber
│   └── data: BasicInfo | TimelineItem[]
├── pageSettings                  // 是否多页、总页数
└── style
    ├── theme: 'minimal' | 'split'
    ├── themeColorTokens          // 主题色/间距 token
    ├── timelineTitleStyle        // 时间线标题样式
    ├── customCSS                 // 用户自定义 CSS
    └── sections[].className      // 单模块追加 class
```

要点：

1. **基本信息模块只有一个**（`type === 'basic'`），其余都是时间线式模块（工作经历、项目、教育等）。
2. 时间线条目的 `description` 存的是 **HTML 富文本**。
3. 持久化 key：`localStorage['resume-data']`（由 `atomWithStorage` 写入）。
4. 导出 JSON 时会把头像 base64 清空，避免文件过大（见 `useJson.ts`）。

改字段结构时：同步改 `types/resume.ts`、`initialResume.ts`，以及读写该字段的 theme / editor 组件。

## 6. 状态与写数据约定

```text
UI 事件
  → hooks（useResumeActions / 各 useXxx）
    → jotai write atoms（resumeStore.ts）
      → resumeAtom（自动写入 localStorage）
        → ThemeRenderer 重渲染
```

- 读：`useAtomValue(resumeAtom)`
- 写：优先调用 `useResumeActions()`，不要在组件里直接拼 `set(resumeAtom, …)`（除非新增一类全局操作）

常用 actions：`updateSection`、`addSection` / `deleteSection`、`updateTheme`、`updateThemeTokens`、`toggleMultiPageMode`、`updateCustomStyle`、`clearResume`。

## 7. UI 主链路

`MainPage` 布局：

```text
┌──────── Header（打印）────────┐
│ 设置侧栏 │     简历预览区      │
│ Theme    │  ThemeRenderer     │
│ Modules  │   ├ minimal        │
│ Pages    │   └ split          │
│ CSS      │                    │
│ Data     │                    │
└──────── Footer ───────────────┘
```

### 设置侧栏五个 Tab

| Tab | 组件 | 做什么 |
|---|---|---|
| 主题 | `ThemeSelectPanel` | 选主题、调色 token、时间线标题样式 |
| 模块 | `ModuleManagementTab` | 增删、排序、显隐、改标题/图标 |
| 分页 | `PageSettingsTab` | 多页开关、模块归属页 |
| CSS | `CustomCssSettingsPanel` | 注入自定义 CSS |
| 数据 | `DataOperationPanel` | 导入/导出 JSON、清空 |

### 主题系统

入口：`ThemeRenderer` → 按 `resume.style.theme` 分发：

- `minimal`：`theme/minimal/*` 自上而下单栏
- `split`：`theme/split/*` 左右分栏

主题色通过 CSS Variables 注入（`themeTokens.ts` 的 `getThemeCssVariables`）。新增主题大致步骤：

1. 在 `ResumeTheme` 联合类型加名字
2. 补 `THEME_TOKEN_DEFINITIONS` / `DEFAULT_THEME_COLOR_TOKENS`
3. 新建主题目录并实现渲染
4. 在 `ThemeRenderer` 注册
5. 在主题选择 UI 暴露入口

### 打印 / 一页自适应

- 打印：`window.print()`，用大量 `print:` Tailwind 工具类隐藏编辑 UI
- 单页内容过多时：`AutoFitSinglePage` 会缩放内容（最低约 0.8），仍溢出则提示警告

## 9. 工程约定

### Git Commit

见根目录 `CLAUDE.md`：

```text
type: 中文描述（≤72 字）
```

`type`：`feat` / `fix` / `refactor` / `chore` / `docs` / `style` / `test` / `perf`

示例：`feat: 添加 split 主题色 token 重置`

### 代码风格

- Biome 管格式与 lint，提交前建议 `pnpm check`
- 组件尽量薄，业务写进 `hooks/`
- UI 基于现有 shadcn 风格扩展，不要另起一套组件体系

### Cursor Agent 保护（重要）

`.cursor/hooks/protect-components.py` 会拦截 Agent 对 `src/components/` 的写入。

含义：

- Agent 默认不能改 `src/components/**`
- 需要改组件时，由你本地手改，或临时调整/关闭该 hook
- Agent 仍可改 `store/`、`hooks/`、`types/`、`pages/` 等

接手后若要放开，改 `.cursor/hooks.json` / 对应脚本即可。

## 10. 部署怎么走

1. 合并到 `main`
2. GitHub Actions `Build and Push Docker Image` 触发
3. 构建多架构镜像并推到 Docker Hub：`${DOCKERHUB_USERNAME}/resumaker`
4. 线上用 nginx 托管，应用挂在 `/resume/`

需要的仓库变量 / 密钥：

- `vars.DOCKERHUB_USERNAME`
- `secrets.DOCKERHUB_TOKEN`

构建产物目录映射：`dist/` → 镜像内 `/usr/share/nginx/html/resume/`。

## 12. 排障速查

| 现象 | 可能原因 |
|---|---|
| 打开 `/` 空白或资源 404 | 忘了走 `/resume/` |
| 刷新子路由 404（生产） | nginx `try_files` 未指到 `/resume/index.html` |
| 刷新后数据还在 / 丢了 | 看 `localStorage['resume-data']`；清空站点数据会丢 |
| 打印多出页眉页脚 / 缩放不对 | 浏览器打印设置；对照 `print:` 类与 `AutoFitSinglePage` |
| 导入 JSON 后布局异常 | 缺字段或 theme 名非法；对照 `Resume` 类型与 `updateResumeStyleAtom` 的兜底逻辑 |
| 头像特别大导致卡顿 | 头像以 base64 存 localStorage；导出时已刻意剔除 |

## 13. 当前已知边界

- 单页应用，几乎没有多路由
- 无自动化测试套件（仓库里有 Playwright 产物目录，但非正式 CI 测试）
- React 版本以 `package.json` 为准（依赖为 18；示例文案里可能仍写 19）
- 主题目前只有 `minimal` 与 `split` 两个

有疑问时优先以代码和类型为准，而不是示例简历文案。
